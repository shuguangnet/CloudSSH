数据库

为 MCP Agent 提供受控的数据库访问。密码在面板端加密保存，Agent 只拿到查询结果，永远看不到凭据。

数据库驱动未安装

当前部署缺少部分数据库驱动，对应类型的连接将无法建立。在服务器上执行以下命令后重启面板：

pnpm add mysql2 pg ioredis

    数据库连接

    每个连接保存一台数据库的访问方式。只读连接会在把 SQL 发给数据库之前拦下写语句。

    只读是防手滑的闸门，不是安全边界——真正的权限控制请在数据库侧用只读账号实现。

    名称类型目标 代理模式

    代理

    数据库在不可直连的网络里时，先经代理转发。SOCKS5 与 HTTP CONNECT 适合堡垒机，SSH 跳板复用面板已有服务器的连接。

    名称类型目标

    查询控制台

    在面板里直接验证 SQL 与权限。结果会按行数/列数/单元格长度截断，只读连接无法执行写语句。

    访问审计

    只记录 SQL 的 SHA-256 指纹、影响行数与耗时，不保存 SQL 正文和任何查询结果。

    时间名称来源 状态行数耗时 SQL 指纹
